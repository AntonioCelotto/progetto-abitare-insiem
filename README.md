# Progetto Abitare Insieme

Portale per accompagnare imprenditori e investitori nell'apertura e gestione di strutture per anziani.

## Stack
- Next.js
- TypeScript
- Supabase
- Vercel

## Prime regioni
- Piemonte
- Lombardia
- Liguria

## Moduli iniziali
- Home istituzionale
- Configuratore "Cosa posso aprire?"
- Database normativo regionale
- Lead e richieste di consulenza
- Immobili
- Professionisti e fornitori
- Dashboard amministratore
